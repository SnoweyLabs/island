# Category and age rating

Only what the public pages say, with one suggestion.

## Category (required; a secondary category and a subcategory are optional)

The page lists, among others: `Productivity` (no subcategory), `Utilities + tools` (subcategories `Backup + manage`, `File managers`), `Developer tools`, `Personalization`, `Business`.

Suggestion: **Productivity**. Why: Island keeps the things a person uses all day one key away and shows what is open, which is what the page's own name for the category says it is for; none of the subcategories of Utilities + tools fits (it is neither a backup nor a file manager).

## Age rating

The page says the questions are required and that the first submission shows a multiple-choice questionnaire (from IARC), then "Save and generate"; the rating is reused for later updates; an existing rating id may be supplied instead.

The questionnaire itself is part of the submission, which needs the owner's developer account: **UNVERIFIED**, not reconstructed from memory or from other sites. The owner answers it. Facts from the code that the answers will probably need, for the owner to read against each question: Island has no violence, no sexual content, no gambling, no user-generated content shared with others, no purchases, no chat or other contact between people, no location, and it connects to nothing on the internet; it hands an address to the person's own browser when they click a site they put on the island, and the content of that site is the site's.
