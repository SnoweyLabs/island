# Chrome Web Store pictures — the add-on

The sizes are those the page states: store icon 128 x 128 PNG (the artwork 96 x 96 with 16 pixels of transparent padding); screenshots 1 to 5, 1280 x 800 (preferred) or 640 x 400; small promo tile 440 x 280 (required); the marquee (1400 x 560) is optional and not made. Drawn by the app's own drawing from the same invented list as the Store screenshots ("Tunes", "Chat", "Editor", "Notes"); nothing shows anyone's own tabs, and no real program's or site's icon is in any picture. They carry no text field or other hidden data (`ShipGuardTests.Png_Pictures_Carry_No_Text_Date_Or_Other_Hidden_Data`).

| File | Size | What it is |
|---|---|---|
| `images/store-icon-128x128.png` | 128 x 128 | The store icon (icon candidate A; the owner chooses, see `ship/store/CE-FACI-TU-store.md`). |
| `images/screenshot-1-1280x800.png` | 1280 x 800 | The island with a page of things, one of them showing two tabs. |
| `images/screenshot-2-1280x800.png` | 1280 x 800 | The small pill while something plays in a tab. |
| `images/small-promo-440x280.png` | 440 x 280 | The small promo tile. |

The add-on's own icons (16, 32, 48 and 128 pixels) are in `extension/icons/` and in the zip, and the manifest names them.
