### The entry and the file

Codex's page gives a command hook as one `command` string (no `args`), with `async: true` for the background. So the entry is the **shell form**:

```json
{ "hooks": { "<Event>": [ { "hooks": [ { "type": "command", "command": "\"<path>\" --agent codex", "async": true } ] } ] } }
```

one group per written event (no matcher: Stop, UserPromptSubmit and Interrupt ignore one by the page, and the others then match every tool). The file is `hooks.json`, plain JSON, the same outer shape
as Claude Code's (`{ "hooks": { Event: [ { matcher?, hooks: [..] } ] } }`). `--event` is not needed: Codex's input names its event (`hook_event_name`). Island.Notify must read `session_id`, `cwd`, `hook_event_name`,
and, for the kind, `tool_name` from Codex's stdin (same names as Claude Code's).

- Connect: adds one group per written event, only where no handler running Island.Notify is already in that event's list; nothing twice; theirs stay, in order, ours go last in each list; new events go after theirs.
  A BOM, an empty or whitespace file, CRLF endings, non-ASCII text and number text are handled as the existing `HookInstaller` does (the file is re-rendered indented, like Claude's).
- Disconnect: removes exactly the handlers that run a program named `Island.Notify` (with `args`: `command` is the program; without: the first word of the shell line, quoted or not, also after a
  leading `&`), whatever form; a group or list emptied by that is dropped, a list the person left empty stays; the `hooks` object that Connect made is dropped when it ends up empty.
  Lookalikes (`Island.Notify2.exe`, `python ...\Island.Notify.exe`, other programs with `--agent codex`) stay (tests).
- Unreadable (not JSON, not an object, `hooks` not an object, one of our events not a list, repeated property, comments, trailing comma, `null`): returned unchanged, `HOOKS_FILE_UNREADABLE`.
  Codex's other file, `config.toml`, is TOML and is not written (BLOCKED rather than a parser made here).
- State: nothing running Island.Notify anywhere under `hooks` -> NotConnected; all six written events -> Connected; some but not all (including one under an event not in today's six) -> ConnectedOlder.
- Safety of the quoting: Connect refuses (`NOTIFY_PATH_INVALID`) a command that holds a quote, `%`, `$`, a backtick or a control character, a relative or network path, blanks around it, or a program not named
  Island.Notify; packaged (`viaAlias`) it accepts only `PackageNames.NotifyAlias` and writes it quoted as well.
- The question: `LinesToAdd` shows what an empty file would hold; `PlaceText` names the file's place; `TrustSentence` is the one sentence for the question screen:
  "Codex asks you once to trust the new hooks (open /hooks in Codex and say yes); until you do, it skips them."
