### Public API (what the main session wires)

Input facts (all records):
- `TermWindowFact(long Handle, int OwnerProcessId, string? ExeName, string? PackageFamily, string ClassName, string Title, int RecencyRank)` — from `OpenWindow` + the window's class; `RecencyRank` 0 = most recently used (feeds `TerminalChoice`).
- `ConsoleWindowFact(long Handle, string ClassName, int OwnerProcessId, long OwnerWindowHandle)` — class `"PseudoConsoleWindow"` or `"ConsoleWindowClass"`; owner window 0 when none.
- `ProcessFact(int Id, int ParentId, string ExeName)`.
- `HelperState { Idle, Working, NeedsYou, Finished }`.
- `HelperSessionFact(string HelperName, string ProjectName, IReadOnlyList<int> Chain, int HangsOnProcessId, HelperState State, long LastHeard)` — `LastHeard` grows with every message; `HangsOnProcessId` 0 when none; `ProjectName` may be empty.
- `TerminalReading(Windows, ConsoleWindows, Processes, Sessions)`; `TerminalReading.Empty`.
- `TerminalTables(TerminalClasses, TerminalPrograms, AiPrograms, HelperPrograms, HelperColors)`; rows `TerminalProgramRow(FileName, Name, Unconfirmed)`, `AiProgramRow(Name, ExeNames, PackagePrefixes, Unconfirmed)`, `HelperProgramRow(FileName, HelperName, Unconfirmed)`; `TerminalTables.Default`, `TerminalTables.Empty`; lookups `IsTerminalClass`, `TerminalProgramOf`, `AiProgramOf(exe, package)`, `HelperOf(exe)`, `ColorOf(helperName)`.

Output:
- `TerminalTile(long WindowHandle, WindowRole Kind, string FirstLine, string SecondLine, TileFace Face, HelperState Ring, int Dots, string? HelperName)`; `WindowRole { None, Terminal, AiProgram }`.
- `TileFace(FaceKind Kind, string? ExeName, string? PackageFamily, string Letters, HelperColor? Disc)`; `FaceKind { ProgramIcon, HelperDisc }`; `HelperColor(byte R, byte G, byte B)`.
  - `ProgramIcon`: draw the icon of (`ExeName`, `PackageFamily`); `Letters` is the fallback made from the program's name, never from the title.
  - `HelperDisc`: a disc of colour `Disc` with `Letters` on it.
- `Ring == Idle` means no ring. `Dots` is `WindowDots.For(helpers in the window)` (0 for one). An AI program's tile with a helper reporting from inside it keeps its texts and face and only gains `Ring` and `Dots` (`HelperName` is null there).

Entry points:
- `new TerminalPage(TerminalTables)`; `IReadOnlyList<TerminalTile> Read(TerminalReading?)` (stateful, page order, never throws: a reading it cannot work out leaves the last tiles); `Tiles` = latest result.
- `TerminalTiles.Build(TerminalReading?, TerminalTables, FirstSeen<long>? helperOrder = null)` — pure, tiles in the reading's window order.
- `HelperFinder.FindByName(processes, PageWindows, tables)` -> `FoundHelper(ProcessId, HelperName, Chain)`; `HelperFinder.WindowOf(chain, projectName, reportedByHook, consoleWindows, PageWindows)` -> `long?`; `HelperFinder.Collect(reading, page, tables)` -> `HelperInstance`; `HelperFinder.ChainOf`, `Normalize`.
- `TerminalClassify.RoleOf(window, tables)`, `CleanTitle(title)`, `CleanName(name)`; `PageWindows.From(windows, tables)`.
- `FirstSeen<TKey>.Order(keys)`.

Rules as built:
- Window role: terminal by class (case-insensitive) first, else terminal by program file name, else AI program by exe or package-name beginning, else not on the page. One handle, one tile (a repeated handle counts once).
- Title: `AgentText.Clean`, leading non-letter/digit runes dropped, cut to 40 (surrogate-safe, trailing spaces trimmed); empty or draws-as-nothing reads as the program's name. Only the first 512 characters of a title are ever looked at.
- Order: `TerminalPage` keeps first-seen order by window handle; reading order inside one reading; gone = forgotten (comes back on the right).
- By name: file name in the helper table; exception 1 (nearest process up the chain, itself included, that owns a page window decides; owns an AI window -> not a helper); exception 2 (a helper with a counted helper among its ancestors is dropped).
- Window of a helper (chain = process itself first): rule 1 console window (the nearest process that owns a console window decides; pseudo -> its owner window, classic -> itself; must be a terminal window of the page, else rule 1 gives nothing and the chain is not walked on); rule 2 `TerminalChoice.Choose` over the page's terminal windows only (titles cut to 512 first); rule 3 only when `reportedByHook`: `TerminalChoice.Choose` over the AI windows; rule 4 null. A helper with no window makes no tile.
- Texts: first line = project when known else helper name; second line = helper name (project known) else cleaned title (empty -> program name); state words ` · working` / ` · needs you` / ` · finished` appended when not idle. Letters = `PickItems.Mark(project or helper name)`. Most urgent helper in a window (needs you, working, finished, idle) gives texts, letters, disc colour and ring; ties go to the helper first seen (`TerminalPage` keeps that order by helper key).

Constants chosen by Claude (named, `(Claude)` in the comments, pinned by `The_Chosen_Constants_Are_Pinned`, `A_Title_Is_Cleaned_And_Cut`, `A_Megabyte_Title_Is_Cut_Without_Reading_It_All`, `The_Helper_Colours_...`): `MaxTitleChars` 40, `TitleReadLimit` 512, `MaxChainUsed` 32, the state words, `UnknownTerminalName` "Terminal", `UnknownHelperColor` rgb(128,128,140), the display names of terminal programs ("Windows Terminal", "Command Prompt", "PowerShell", "WSL", "Bash", "Console", "WezTerm", "Alacritty", "Mintty").

## 6. How to wire it
1. Each reading (page up, every 2 s): build `TerminalReading` from the window lister (`OpenWindow` + class name -> `TermWindowFact`, `RecencyRank` = position in the island's order), the probe (`ConsoleWindowFact`), the process list (`ProcessFact`), and the sessions of section 3 (`HelperSessionFact`). Under `--selftest` hand in invented facts or `TerminalReading.Empty`.
2. Keep one `TerminalPage(TerminalTables.Default)` for the app; `Read(reading)` returns the tiles in page order. Identity of a tile = `WindowHandle`. Compare the new list with the old one by value (the records are value-equal) to redraw only the tiles that changed.
3. Draw: `FaceKind.ProgramIcon` -> icon of (`ExeName`, `PackageFamily`) via the icon source, `Letters` as fallback; `HelperDisc` -> disc colour + `Letters`. Ring from `Ring` (Idle = none), dots from `Dots`. Click -> `BringForward(WindowHandle)`.
4. Tests use `TerminalTables` of their own (`new TerminalTables(...)`) for invented programs.
