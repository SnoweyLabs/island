Auditor "capsule" of WORK-ORDER-12.md §5 "Every promise has a proof". Written 2026-10-07 by Claude Sonnet 5.5 in the worktree `au-capsule` (branch `au-capsule`, from main `a66c137`). Nothing under `src/`, `tests/` or `extension/` was changed; nothing was started (no app, no self-test, no window, no capture).

**Area.** The shape and look of the capsule, the fly-in and fly-out, springs and fixed steps (EVALS M), the rim light and its three kinds (WO12 §2), the three glasses and Blur, the modes and what may appear over a game (EVALS X), which screen and scaling (EVALS W), the settings screen's ball motion (EVALS G), window placement and click-through, and the hidden/open cost.

**What a proof is here.** A unit test as `Project` `Class.Method` that I found in `tests/` (the name is checked against the sources by a script, see the end), or a self-test check as the exact text of its `report.Check("...")` in a `src\Island.App\*Stage.cs` file that I found. "The code does it" is not a proof; a test that would stay green when the promise broke is not a proof either (several rows say so).

**Kinds.** **PROVED**; **NO PROOF** (with the smallest test that would prove it); **PERSON ONLY** (nothing but a person can see it; the row says why and whether STATE.md already lists it); **REPLACED** (a later work order or a decision changed it). One row has one kind. When a promise is partly proved and partly not, the row is **NO PROOF** and its note says which part holds; a "Done means" row judges only its own sentence (verify green, the file exists, the named tests exist, the human item is listed), and the body promises of that section that have no proof are in part 5.

Failed: 0, Passed: 284, Skipped: 0, Total: 284` (the filter is in the command list at the end). The self-test checks were not run (forbidden); their text was matched against the stage sources and the stage code that produces each was read for the checks I rely on.
