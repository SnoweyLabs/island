## 0. How to read this

Kinds, in the third column of every table:

- **PROVED**: a unit test or self-test check I FOUND in the worktree, and that would go red if the promise broke.
- **PROVED+GAP**: the core of the promise is proved by what is named; a named part of it is not. The part is in the last column, with the smallest test that would prove it.
- **NO PROOF**: nothing found that goes red when the promise breaks (or the named test is missing, or tests a function the app never calls). The last column holds the smallest test.
- **PERSON ONLY**: only a person can see it; the last column says whether it is already in STATE.md "De verificat de Dan" (RO half, "Ce era deja" = the numbered list, X1-X3 = add-on, K1-K5 = WO10, N1-N13 = WO7).
- **REPLACED**: a later work order or a decision of Dan's changed it; the last column names which.

Names: unit tests as `Project` + `Class.Method` (project is `Island.Tests` unless said); self-test checks as the exact text of the `report.Check("...")` literal in the `src\Island.App\*Stage.cs` file named (where the source literal has `\"` it is repeated here; `{i + 1}` is source text); add-on tests as file + test title in `extension/tests` (I did NOT run node: the add-on titles are found by grep only).

## 5. Findings (the three biggest first; each with the evidence and the smallest repair; none changes a file here)

- **F-1 (MEDIUM, from reading code; not reproduced, I may not start the app)**: `IconCache.Fetch` (`src/Island.App/PickPages.cs`) stores the result `_icons[pick.Id] = icon` even when it is `null`, and `Get` never asks again. `ProgramIcons.ProgramIcon` knows a miss must not be cached ("a miss is not cached: the catalog may not have been read yet"), but the catalog's `Loaded` event is wired to nothing in `AppHost`/`AppWorld`, and the catalog is awaited only on a first start (`StartersInstalled`). The first `ItemsOf` happens at `IslandMachine` construction (`_capsuleTargetWidth = CapsuleLayout.SizeFor(Contents)` calls `itemsOf` for page one), right after `RealWorld.Create` has started the catalog's first read. A program that only the catalog can locate (anything not under the Windows folders) then keeps its letters until the next start.
